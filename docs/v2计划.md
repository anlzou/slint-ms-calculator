# v2 计划 — 科学型模式（首个扩展模块）

> v1（标准型 + 历史 + 记忆 + 键盘 + 主题/设置 + 置顶模式）已完成，见 README.md。
> 本文档是 v2 里程碑计划：先在模式抽屉落地「科学」，其余模块列入 backlog。

## 1. 范围（对照 Win11 计算器科学型）

**v2.0 做：**
- 角度模式切换：DEG / RAD（GRAD 不做）
- 三角函数：sin cos tan，「2nd」开关切换反函数 sin⁻¹ cos⁻¹ tan⁻¹
- 对数/指数：ln、log₁₀、eˣ、10ˣ、2ˣ
- 幂与开方：x²、x³、xʸ（二元）、√x、∛x、ʸ√x（二元）
- 其他：n!、|x|、mod（二元）、π、e、rand、括号 ( )
- 模式切换：抽屉「科学」可点，顶栏标题随模式变化（标准/科学），科学键盘与标准键盘互换，历史/记忆共用
- 「科学」菜单项解除置灰

**v2.0 不做（backlog）：**
- exp（E 计数法录入）、floor/ceil、sec/csc/cot、复数、单位换算显示
- 程序员 / 日期计算 / 转换器 / 绘图 模式

## 2. 设计决策（贴合现有架构）

1. **一元函数沿用 `NumText` 即时求值模式**：按 `sin` 即对"当前操作数"求值并压入
   `Tok::NumText(值, "sin(30)")`——与现有 x²/√x 行为一致，解析器零改动。
2. **二元函数扩展 `Op`**：`Op::Pow`、`Op::Root`（y√x：lhs 次根 of rhs）、mod 作 `Op::Mod`。
   优先级：幂/根 高于 ×÷（右结合）；mod 与 ×÷ 同级。
3. **角度模式进引擎**：`apply_unary` 增加 `AngleMode` 参数（或新增 `apply_unary_in`），
   sin(30°)=0.5 精确化（π/6 特例走 f64 后 round 到 1e-12 容差）。
4. **精确值策略**：整数幂 `Rational.pow_i` 保持精确（2^10=1024）；超越函数（三角/对数/
   eˣ/rand/n! 大数）一律 `Value::Approx(f64)`；n! 在 ≤170 且为整数时用 i128 链乘转 f64。
5. **括号**：引擎已支持 `LParen/RParen`，控制器补 `( )` 按键路径 + 显示。
6. **模式状态放控制器**：`App.mode`（Standard/Scientific）+ `angle` + `second` 由按键码驱动；
   UI 只读属性回显（DEG/RAD 文本、2nd 高亮）。

## 4. 风险

1. **f64 精度尾巴**（sin(30)=0.4999999…类）→ 统一在 `value_to_display` 的 16 位有效数字截断，
   三角/对数结果先做 1e-12 容差吸附（0/±1 特例）
2. **定义域错误**：负数开偶次根、log(x≤0)、除零 mod → `CalcError::InvalidInput` 本地化文案
3. **xʸ 的 0^0**：原版=1，跟随
4. **科学键盘行多、窗口最小高度**：320x480 放不下 6 行功能键 → 「显示更多」默认收起，
   展开时键盘区可滚动或窗口 min-height 提升到 520
